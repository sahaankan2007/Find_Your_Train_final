PRD — Find Your Train
1. Product Overview
Website Name: Find Your Train
Purpose:
A responsive frontend prototype for dynamically displaying train location, ETA, delay, route and
operating conditions.
The frontend will be integrated later with a backend containing the CatBoost ETA prediction model.
Frontend Scope
The frontend must provide:
Passenger interface
Admin interface
Interactive India map using MapTiler
Train route and station visualization
Live/simulated train location
ETA and delay display
Weather, temperature, speed and congestion display
Admin control of operating conditions
5 km checkpoints for admin
Real-time reflection of admin changes on passenger view
Dark/light mode
Responsive design
Mock data mode for demonstration
Not in frontend scope
Do not implement:
CatBoost model
ML calculations
Backend/database
GPS ingestion
Railway control logic
Real authentication system

6. Checkpoint System
Create checkpoints every 5 km along the railway route.
Checkpoints are ADMIN ONLY.
Passengers must never see checkpoint controls.
Admin Map
Show:
CP-001
CP-002
CP-003
...
Each checkpoint can show:
Checkpoint ID
Distance
Status
Current conditions
Admin can select:
Activate Checkpoint
The checkpoint utility should calculate points along the actual route geometry rather than simply
connecting stations with straight lines.
Use GeoJSON route data and Turf.js or allow the backend to provide checkpoint coordinates.

RailRadar — Optional
Not required for the frontend prototype.
It can be integrated later through the backend if the team wants real train location, route or station
data.
Recommended architecture:
RailRadar
   ↓
Backend
   ↓
Find Your Train Frontend
Do not make the frontend directly dependent on RailRadar.
Weather API — Not Required
For this prototype, weather and temperature are controlled by the admin, so a separate weather API is
unnecessary.
13. Acceptance Criteria
The frontend is complete when:
Passenger/Admin entry works.
All four trains are available.
Passenger can select a train.
Interactive MapTiler map works.
Route and stations are displayed.
Train position is displayed.
Passed stations update automatically.
ETA and predicted delay are displayed.
Weather, temperature, speed and congestion are displayed.
Admin can modify conditions.
Admin-only checkpoints work.
Passenger cannot access checkpoint controls.
Admin changes appear in Passenger mode.
Mock mode works without a backend.
Backend API integration can be added without rewriting the UI.
Light/dark mode works.
Mobile and desktop layouts are responsive.
